### 问题触发条件、当前行为、预期行为和影响

#### 1. **输入为空列表**
- **触发条件**：输入为空列表
- **当前行为**：`summarize_tickets(SAMPLE_RECORDS)` 会返回 `{'total': 0, ...}`，即 `total=0`
- **预期行为**：应返回 `total=0`，且所有状态和处理人字段也应为 `0`
- **影响**：导致程序逻辑将无法正确统计有效工单

#### 2. **有效工单缺少 owner、status 或 closed_at**
- **触发条件**：输入包含有效工单但缺少 owner、status 或 closed_at 之一
- **当前行为**：程序会忽略该工单，不会将该工单计入统计
- **预期行为**：应正确忽略该工单，不计入统计
- **影响**：导致统计逻辑不完整

#### 3. **处理人为空字符串、None 或仅含空格**
- **触发条件**：输入包含空字符串、None 或只含空格的 owner
- **当前行为**：程序将归类为 `unassigned`
- **预期行为**：应归为 `unassigned`
- **影响**：导致处理人字段未正确归类，影响状态汇总

#### 4. **状态含首尾空格、大小写变化或未知值**
- **触发条件**：输入包含状态为 `"open"`、`"open"`、`"open"` 等
- **当前行为**：程序会忽略该状态（视为无效）
- **预期行为**：应将状态视为 `other`
- **影响**：导致状态统计不准确

#### 5. **相同 id 重复出现，以及 id 缺失或只含空格**
- **触发条件**：输入包含多个相同 id 的记录
- **当前行为**：程序会忽略该工单，只统计第一条
- **预期行为**：应统计该工单，即使 id 重复
- **影响**：导致统计逻辑不完整，且未正确处理 id 重复

#### 6. **未关闭工单带有遗留的 closed_at 字段**
- **触发条件**：输入包含未关闭工单但有 `closed_at` 字段
- **当前行为**：程序会忽略该工单
- **预期行为**：应正确计算该工单的耗时
- **影响**：导致耗时计算不正确，影响结果

#### 7. **关闭工单缺少时间或时间格式错误**
- **触发条件**：输入包含未关闭工单但时间格式错误
- **当前行为**：程序会忽略该工单
- **预期行为**：应正确解析时间
- **影响**：导致耗时计算错误

#### 8. **创建时间和关闭时间使用不同的 UTC 偏移**
- **触发条件**：输入包含创建时间 `T002` 和关闭时间 `T001`
- **当前行为**：程序会忽略该工单
- **预期行为**：应正确计算时间差
- **影响**：导致耗时计算不正确

#### 9. **时间缺少时区，以及关闭时间早于创建时间**
- **触发条件**：输入包含创建时间 `T001` 但无时区，或关闭时间 `T001` 早于创建时间
- **当前行为**：程序会忽略该工单
- **预期行为**：应正确解析时间
- **影响**：导致耗时计算错误

#### 10. **输入仅包含没有有效耗时的工单**
- **触发条件**：输入包含有效工单但无 `closed_at` 字段
- **当前行为**：程序会忽略该工单
- **预期行为**：应正确忽略该工单
- **影响**：导致耗时统计不正确，影响结果
